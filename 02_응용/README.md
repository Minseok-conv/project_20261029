
- full-batch와 mini-batch의 차이: 
full-batch는 전체 데이터셋을 말하고 mini-batch는 전체 데이터셋을 작은 크기로 나눈 것을 말한다. 
- 마지막 batch가 작을 수 있는 이유: 
전제 데이터셋의 개수가 batch수로 나눠지지 않는 경우 마지막 batch의 사이즈가 작을 수 있다. 
- 입력·정답·모델을 같은 device에 두는 이유: 
model,입력,정답을 같은 device에 둬야 그들 사이의 연산을 수행 할 수 있다. 
- 수동 갱신 뒤 loss와 갱신 전 loss를 구분하는 이유: 
갱신 전 loss와 갱신 후 loss를 비교 함으로써 모델의 성능 증가율을 평가하고 훈련에 적절한 epoch수를 판단할 수 있다.
